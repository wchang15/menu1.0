# Menu 1.0 - Historical Snapshot

**Status: retained for reference; not the current maintained application.**

This repository preserves an earlier React/Next.js restaurant tablet-menu editor
and player with Supabase storage, local caching, and an iOS Capacitor wrapper.
Its older dependencies, asset-signing routes, and setup have not been brought up
to the current review baseline. Do not deploy this snapshot or add live credentials.

## Current Work

- [Tablet menu application](https://github.com/wchang15/menu): current setup,
  Storage access instructions, dependency updates, and build CI.
- [Restaurant ordering demo](https://github.com/wchang15/restaurant-ordering-demo):
  TypeScript ordering, server pricing, Stripe test webhooks, staff access, and tests.
- [Portfolio case study](https://www.woochangchang.com/restaurant-platform.html).

The source and commit history are preserved. This status note does not claim that
the historical snapshot passes the checks in the current repositories.
